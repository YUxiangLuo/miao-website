每 6 小时与 GitHub 最新 release 同步，当前镜像版本 …。安装前请核对 sha256sums.txt。

一键安装 / 卸载（无需访问 GitHub）
# 一键安装为 systemd 服务（按机器架构自动对应 amd64/arm64）

curl -fsSL https://miao.vesein.dev/install.sh | sudo MIAO_BASE_URL=https://miao.vesein.dev/dl bash

# 卸载并清理全部痕迹

curl -fsSL https://miao.vesein.dev/remove.sh | sudo bash
文件说明
miao-rust-linux-amd64Linux amd64 单二进制（musl，内核/规则集/面板全内嵌）
miao-rust-linux-arm64Linux arm64 单二进制（树莓派 / ARM 盒子 / OpenWrt）
miao-windows-amd64-setup.exeWindows 桌面版安装包（NSIS，需 WebView2；Win10/11 x64）
install.sh安装脚本：二进制 → /usr/local/bin，配置 → /etc/miao，注册 systemd
remove.sh卸载脚本：服务、二进制、配置、运行时文件全部清理
sha256sums.txt二进制与安装包的 SHA256 校验和，随每次同步重新生成
VERSION当前镜像对应的 release tag
